## 首轮真实研究的关键检查

Codex 每次复跑仍必须核对：源响应/因子单位、行情覆盖；Qlib 官方版本与 Parquet 转换 API；训练数据中标签是否已成熟、训练/验证/测试隔离；Qlib 模型评分、动量及真实标签的**MultiIndex 层级顺序与键对齐**（只重命名索引不等于正确重排）；横截面分母、缺失与重叠样本；研究产物的实际生成时刻与**假定历史信号截止**的区别。

当前实现按具名层级重排索引，先取三列有限值交集，再共同排除不足截面/常数列日期。必须在**相同日期和证券对**上计算两个排序指标，并报告原始交集、有效分母、排除原因、各年度或时间段、阴性结果。观察到 RankIC 差异不直接证明统计显著性；重叠的10日目标不可当作独立实验重复计数。

### 首轮可接受结果

- **工程结果**：真实行情经 DuckDB/Parquet/官方 Qlib 转换可追溯，运行可重复；模型成功训练、推理、计算与基线**配对**的 RankIC 报告，原始配置/版本/快照/关键日志清楚。
- **探索性结论**：只能判断该固定样本/当前历史数据下是否存在排序信息；不把“时间先后测试”直接标成严格 PIT OOS。
- **失败同样交付**：如果源权限、复权链、Qlib API、缺失特征或标签成熟度阻断，记录具体未满足条件、受影响范围和可复现步骤；不得采用假源替代真实成果。

## 方向预测实验 WP-AQL-DIRECTION-FORECAST-01

2026-11-17 在读取本实验评价结果前冻结，基线 main `62a1c13`、冻结提交`7dc5c02`。现已完成真实滚动验证及独立最新日推理，整体无增益，见[方向结果](WP-AQL-DIRECTION-FORECAST-01-RESULTS.md)。这是新的方向分类假设；首轮排名研究已完成、整体阴性，历史配置/模型/快照/报告不修改。本节同时作为本任务设计和实施计划，避免另建重复协议。官方 [LGBModel](https://github.com/microsoft/qlib/blob/v0.9.7/qlib/contrib/model/gbdt.py) 提供 binary 训练/概率输出；[Alpha158](https://github.com/microsoft/qlib/blob/v0.9.7/qlib/contrib/data/handler.py) 的默认截面标签归一化必须显式替换。

### 目标、数据与实现边界

- 唯一周期10交易日：T盘后且源数据齐备，r=adjusted_close(T+11)/adjusted_close(T+1)-1；y=1 iff r>0，否则0。零收益计入未上涨，单列计数；非有限/未成熟标签保持缺失。不是当前起算收益、价格曲线、震荡分类或账户净收益。
- 固定 `configs/first-study-cohort.txt` 30股。历史使用原已授权完整快照；新数据只写新的外置盘批次和快照。固定当代股票池、修订及可用时钟未知，仍为回顾性验证，不能称真正未见OOS或严格PIT。后续自然前瞻另存。
- 由官方表达式解析器逐一计算158特征的左右扩展窗口，拒绝未来特征。训练/预测前要求完整最大回溯区间（至少前60交易日且以实际表达式为准）的原始OHLC/VWAP/volume齐全；缺口行不填价、不压缩日历，保留在输出分母。使用完整provider日历核对原生收益/20日动量与独立shift，保留缺失。
- 分类学习处理器仅 `DropnaLabel` 加本库保持缺失的0/1标签处理器；推理处理器显式为空（LightGBM处理数值缺失，无需估计特征归一化参数）。历史r仅在label组，永不进入feature组。最新入口直接加载158特征与可信模型，不加载未来标签、不调用fit。

### 预先冻结时间安排和模型

配置版本 `configs/direction-study.json` 为唯一机器配置，变更需新实验身份，不因结果调参。

- 评价信号日2024-01-03至2026-09-30；按日输出、每月首个交易日盘前重训（月内首次预测之前已完成）。以该月首交易日 P 的前一交易日为成熟截止，绝不使用P当日或未来行情/标签更新模型。数据最早2019-01-02，前最大回溯区间只用于预热。
- 从P向前按完整交易日历：calibration为最近126个已成熟信号日（末日+11 <= P-1）；early-stop为此前126信号日，末标签结束日严格早于calibration首信号日；train为再此前756信号日，末标签结束日严格早于early-stop首信号日。相邻分段留11信号日；同日全部股票属于同段。窗口不足拒绝，不自动缩短。
- Alpha158 + 官方 LGBModel(loss=binary)，learning_rate=.05、max_depth=6、num_leaves=31、num_threads=4、seed=23、deterministic=true、force_col_wise=true；最多240轮、早停30。只用train拟合；valid只早停；calibration只拟合校准。阈值固定.5，无超参搜索或测试后调整。
- B0用同一train段已成熟合法标签的上涨比例，Beta(1,1)平滑。B1用同一train段20日动量的一因子标准化+逻辑回归，C=1、lbfgs、max_iter=1000；标准化仅train拟合。基线与模型使用同一质量资格及日程，单独报告输出与共同范围。
- 主比较概率是Qlib原生binary概率经独立calibration段Platt校准后的值（logit(p)作为单特征逻辑回归，C=1、lbfgs、max_iter=1000）。原始binary概率同时报告，绝不使用旧排名分数。校准段少于100行或缺任一类别时标记UNAVAILABLE，不回退伪称校准。B1为原生逻辑概率，不追加校准；B0为历史频率。校准状态仅表示时序拟合资格，非已通过概率可靠性验收。

### 评价与接受边界

- 主指标：共同证券日期上逐日截面平均log loss、再日期等权；报告 calibrated_model-B0 与 calibrated_model-B1，负值为好。裁剪仅计算log时epsilon=1e-6，保留原概率。原始模型同口径辅助比较。
- 辅助：Brier（同样日期等权）、固定10个等宽概率箱（日期权重）、平衡准确率、混淆矩阵（证券日期计数）；全段与逐年、逐证券完整报告；日期/行数、正/未上涨/零收益、缺失/质量原因与输出覆盖。不因全涨/全未上涨或常数预测剔除日期；单类别平衡准确率标记不可计算，主指标保留。
- 不确定性：主差值的每日序列采用固定长度20交易日移动时间块bootstrap，2000次、seed=23、95%百分位区间；每次抽完整日期保留截面关联，不重抽股票。分段缺测保留交易日轴，报告有效日。10期重叠和横截面相关使证券日期非独立证据。
- 只有两条主比较全段区间上界均<0且每个完整报告年度差值均<0，才可称“有限回顾性增益”；仍不能采用交易。均值不优标记无增益；其余为证据不足。Brier改善不代表校准通过；校准曲线、判别能力分别解释。不得追加搜索。

### 产物、实施顺序与验证

1. 文档/配置先冻结提交；建立 `direction_data.py` 负责原生特征、完整日历、缺失标签及时序分段；`direction_study.py` 负责官方月更训练、独立校准、基线与模型身份。
2. `direction_evaluation.py` 独立概率评价；`direction_inference.py` 无标签最新推理及追加成熟复盘。CLI暴露 run-direction-study / infer-direction / review-direction；正式外置盘运行脚本串起真实采集/导出/转换和研究，逐阶段保存失败。
3. 每月保存model.txt、校准/基线JSON、特征定义/处理器配置、分段与成熟截止、代码/依赖/快照哈希；模型不使用不可信pickle。逐股历史输出和最新批次留私有盘，公开仅脱敏汇总及报告。
4. 最新推理输入必须包含来源交易日历及实际抓取时刻；15:00收盘后尝试当日源数据，仍须检查30股当日日线/复权及回溯区间齐备；缺源不能以时钟替代验证。无法取得最新数据明确STALE/BLOCKED，不把测试末日当今天；未来区间交易日不足时明确相对T+1/T+11定义、日期UNKNOWN。
5. 预测JSON独占新文件且哈希留存；成熟后新建review记录，绑定原预测SHA和复盘快照。不得覆盖原预测，缺标签继续PENDING；修订差异不覆盖早先复盘。
6. 必要单测覆盖标签、隔离、常数截面、覆盖、块法、索引与产物；正式真实链路验证158特征、0/1学习标签、月更训练/推理、同输入重现、标签不可用推理、模型/快照篡改拒绝。真实研究结论与最新推理工程分开验收；TSP/MRA和交易实例不动。
