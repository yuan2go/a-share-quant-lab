# 数据合同：DuckDB 来源、Parquet 冻结、Qlib 转换

**实现和验证范围**：src/ashare_quant_lab/market_store.py、market_ingest.py、market_export.py、qlib_dump.py；已通过合成记录的 DuckDB/Parquet CI。真实固定30只股票的来源与官方Qlib链路已实测，详见[运行结果](WP-AQL-FIRST-REAL-RESEARCH-01-RESULTS.md)；全市场、PIT及经济交易资格未验证。

## 数据权威与生命周期

| 层 | 当前 Owner / 内容 | 可做出的结论 |
| --- | --- | --- |
| DuckDB | 本仓库市场采集记录：captures、daily_bars、trade_sessions；Schema 指纹阻止误写其他库 | 某次接口采集了哪些记录，不代表历史公开可得 |
| Parquet | 从已完成采集导出的证券级调整后行情，manifest v2、文件 SHA256、贡献 capture_id | 本地字节与采集批次的可复现投影 |
| Qlib Binary | 官方 dump_bin.py 从已校验 Parquet 转换，保存源 manifest 与转换器摘要 | 已逐字段核对Parquet→float32 Binary、全文件哈希与原生日历位移标签 |
| TSP 本地缓存 | 原生行情 K 线与展示数据；使用只读历史数据网关 | 页面展示副本，不能独立决定研究数据版本 |

不再使用 CSV 作为**现行研究链路**，也不要求 PostgreSQL。需要服务并发或速度改造时，以真实吞吐、磁盘、延迟证据为准。

## 已实现的采集/查询机制

每次采集申请新的 capture_id：RUNNING → COMPLETE 或 FAILED。每只股票导入在事务中写入；仅 COMPLETE 批次可被查询和快照采用，FAILED 残余行情被排除。TSP原始记录查询仍按证券/日期选择最近完成记录；**研究快照**改为选择覆盖全部请求日期/证券的单个COMPLETE批次，可显式指定capture_id。没有完整批次就拒绝导出，不能拼接历史累计因子。旧成功批次仍可供追溯。

已存字段：不复权 OHLC、成交量（库内由 Tushare 手转换为股，TSP网关输出再除100为手）、成交额（千元转换为元）、Tushare 累计复权因子、采集时点与交易日历（目前 SSE）。TSP 需要的是**单次事件因子**，不能直接把累计因子写入 ex_factor。

DuckDB 当前仅支持独立进程单写。已有其他读网关占用同一文件时，先停网关再采集；未实现跨进程在线读写切换。没有对 TSP/MRA 数据库写入授权。

## 尚未封闭的数据真实性问题

1. **修订边界**：研究快照的隐式混合修订已阻止；TSP最新原始记录读法仍不具有研究快照资格。同次重复采集一致、除权昨收与累计因子一致，不代表历史公开版本或分红独立核实。
2. **数据覆盖**：首轮56,840条日线，相对30×1,897开市日缺70个证券日期；缺失原因未逐一核实，保持UNCLASSIFIED，未补行情。Manifest列出缺失日期；模型评价剔除共同缺失标签/动量，完整分母见报告。
3. **证券池和公司行为**：当前研究固定30只股票，不含历史完整上市/退市/ST/指数成分、公告公开时钟、完整现金分红及证券实际可交易状态。不能宣称全市场 PIT 或净收益正确。
4. **快照强度**：manifest SHA 证明文件内容相符，不证明来源曾在历史研究时点公开可用；数据库本身也不是 WORM 审计系统，恢复与备份资格未验证。
5. **采集 API**：探针现核对trade_cal、daily、adj_factor及均价维度；本轮三接口真实可用。完整采集保留原始响应与哈希，只落外置盘。响应上限硬拒绝，较长股票历史按日期拆分；不代表任意权限、全市场吞吐或长期源稳定性。

任一缺口若会改变目标标签、股票排序或研究结论，应停止相关结论升级，保留有限探索结果与真实失败原因。
